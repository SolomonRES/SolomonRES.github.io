Course Description

CSCE 242 focuses on the fundamentals of building modern web applications; the course introduces core web technology used in client server environments. Topics include creating and styling websites with HTML, CSS, and JavaScript. The course also covers working with structured data such as JSON and applying object oriented concepts in JavaScript. By the end of the semester, the goal is to understand how client side and server side components interact to form a complete web application.
